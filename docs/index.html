Everything you reach for

Not an approximation. The tools are in the same places, named the same things, and behave the same way.

✏️

The full toolbox

Pencil, Fill with colour, Text, Eraser, Colour picker and Magnifier, plus rectangular and free-form selection.

🖌️

Nine brushes

Brush, calligraphy pen and brush, airbrush, oil, crayon, marker, natural pencil and watercolour — each with its own texture.

⬡

23 shapes

Every shape from Paint's gallery, with outline and fill styles. Hold Shift for a perfect square or circle.

🗂️

Layers

Keep labels on their own layer and move or hide them without touching the drawing underneath. Reorder, set opacity, merge, flatten.

🎨

The palette you know

Paint's exact 20 default colours, named on hover, with Colour 1 and Colour 2 on the left and right mouse buttons.

🔤

Text you can place

Drag the box where you want it and watch the font, size and colour change as you type, before you commit to it.

💬

Hover help everywhere

Every control explains itself in plain language — written for someone new to the Mac, not for a developer.

🔍

Pinch to zoom

Smooth trackpad zoom anchored under your fingers, two-finger double-tap to fit, 12.5% to 800%.

📐

Canvas presets

HD, 2K, 4K, and A4 or Letter at 150 dpi for worksheets and handouts. Or type any size you like.

💾

Ordinary files

Opens and saves PNG, JPEG, BMP, GIF and TIFF. No library, no accounts, no sync — just files.

Why this exists

It began as a Christmas present. A primary-school teacher had spent years building her lessons around Microsoft Paint — quick diagrams, labelled worksheets, cropped photos — then switched to a Mac and found that nothing worked the way she expected.

The Mac has no shortage of drawing apps. What it lacked was the one she already knew. So iPaint copies Paint's behaviour rather than reinventing it: muscle memory is the whole feature.

It turns out a lot of people are in the same position. If you are one of them, it is yours.

Install it

Building takes about twelve seconds and needs nothing but Apple's own developer tools.

Prefer not to build it? Grab the latest ready-made app from the Releases page. Or build it yourself: 

# 1. Get Apple's command line tools (skip if you have Xcode)
xcode-select --install

# 2. Clone and build
git clone https://github.com/g4bcloud/iPaint.git
cd iPaint
./scripts/build-app.sh

# 3. Install it like any other app
cp -R iPaint.app /Applications/

Then open iPaint from Launchpad or Spotlight.

On first launch, macOS will warn that the app is from an unidentified developer — the build is signed on your own machine rather than notarised by Apple. Right-click iPaint in Finder, choose Open, and confirm. You only do this once.
